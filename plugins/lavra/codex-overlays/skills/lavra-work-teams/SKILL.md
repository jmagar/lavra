# Codex bead team

Inspect the epic, its children, and dependency graph with `bd show`, `bd ready`, and `bd blocked`. Claim the coordination issue. Assign independent children to available Codex subagents using the collaboration tools when available. Each worker prompt must name its bead, owned files, acceptance criteria, test command, and the fact that workers share the checkout. Codex subagents are coordinated by the parent task.

Wait for worker results, inspect the shared diff, resolve overlaps, run combined validation, and update or close each bead according to evidence. Record a concise handoff on the epic. Keep publication and merge decisions under the user's instructions.
