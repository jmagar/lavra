# Agent-native audit

Read the `agent-native-architecture` skill and its relevant references. Inventory user actions, agent tools, available context, state and data access, permission boundaries, feedback, and test coverage. Map each user capability to an agent capability with file evidence. When independent passes would help, assign bounded read-only sections to available Codex subagents and integrate their results. Keep the number of workers within the current concurrency limit.

Report each principle with a concrete numerator and denominator where measurable, the missing capabilities, impact, and the smallest actionable fix. Mark unverified claims as unknown. Do not infer product parity from a model-only demonstration.
