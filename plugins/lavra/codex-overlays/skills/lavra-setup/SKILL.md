# Set up Lavra in Codex

Inspect the repository, existing `AGENTS.md`, `.beads`, `.lavra`, and `.codex` directories before changing anything. Run `bd prime`; initialize beads only if the repository is not already initialized. Preserve user configuration and installed Codex components. Create or update Lavra's project configuration through the provided installer, then verify skill and agent discovery, hook JSON, and the Context7 MCP entry. If independent repository analysis would help, assign bounded read-only Codex subagents to examine stack, architecture, and conventions, then integrate their findings.

Report what was created and the commands needed to use it. Never overwrite existing project instructions without the user's request.
