# Durable task tracking

Use `bd prime`, `bd create`, `bd update`, `bd dep add`, `bd show`, and `bd close` to track work. Create a parent issue for an independently valuable objective and children for separately verifiable pieces. Include acceptance criteria and link dependencies when order matters. Keep task status aligned with actual code and test evidence.
